# Inventory of evidence/drive

55 files. The brief expected 50 plus late arrivals. Late arrivals are all here. Every workbook was read. One image file inside a ZIP stayed unread.

**How I counted.** "Live" is the number of formula cells after conversion by LibreOffice. "Pasted" is the count of numeric and date cells minus live formulas. "Names" is the largest count of distinct values in a Ticker or Name column. "Dead links" is the count of external workbook links. None of them resolves on this machine.

**Caveat on cached values.** I read cached values from the original BIFF file with xlrd, and formula text from the converted file. Macros stayed off. UDF cells show the last value Excel saved. TABLE data tables in `E2C_CG1.2_RiskAnalysis.xls` Control&Report show #NAME, so the values-only copy is the only record of them.

## Replication priority

The top 5 are all a replicator needs.

1. `04_raw_data/12AdjE2C_Data_27_9_2005 (47.9MB, Alphadyne folder).xls`: The master backtest. 151 weekly dates, 170 names, 19,489 rows. Holds raw inputs, solver output, PIT regression, signal, sizing, P&L, stress, VaR, capital and NAV. Scenario sheets hold pasted results. Saved by jplardy on 8 Dec 2005.

5. `03_backtests/Results.xls`: 20,789 rows, 211 names, 105 dates, Aug 2003 to Aug 2005. Pasted output of an external library named CFtw5. 1,560 rows failed to calibrate. DPS is frozen at end of period.

## Notes on files that mislead by name

- `12AdjE2C_Data_27_9_2005 (17.3MB, ...).xls` is a ZIP. Excel would not open it.
- `Clean Quarter Data.xls`: sheet `9_30_05` holds 2004-09-30, and sheet `12_31_05` holds 2004-12-31. The year in the sheet name is wrong.
- `Regression_Portfolio 9_30_05.xls`: its two regression sheets are the same pasted numbers as the 6_30_05 file.
- `PointInTime.xls` is one snapshot. It holds no time series.
- `E2C_PIT_Analysis.xls` is one snapshot too. Real point-in-time work is in the master, sheet `Reg`.
- `SampleE2CBackTest.xls` is a true backtest. It is not a sample of a bigger file by row, because its parameters and bugs differ from the master.
- `E2C Sample.xls` has nothing to do with the backtest. It is an extract of the Minimum MTM sheet.
- `creditgrades 20100722.xls`: column "ImpAvol" is historical asset vol, and column "AvgAvol" is implied asset vol. They are swapped.

## Outside the evidence folder

`/home/ak/Downloads/Creditgrades_model.xlsm`, 27 KB, md5 `30b473eb385d6dbcdd60155f1eca26c4`. Read without running macros.

- **Who wrote it:** file properties say Emrah Ozpeynirci, created and last saved 2018-01-16. Nothing in it names the user, so it does not look like the user's own work.
- **What it is:** a small CreditGrades implementation. `Sheet1` works one DPS and one survival probability. `Sheet2` shows a 1-year PD for one unnamed company, Q4 2003 to Q2 2008, with barrier vol 0.1 and 30-day vol.
- **VBA:** `CG_PS` is the same survival formula as `E2C`, with asset vol at the current price. `CG_CDS` is the same spread formula but has no 360/365 factor. No cell calls `CG_CDS`, so no cached value tests it. `iterate` and `BSd` use ranges and inputs that the file does not hold.
- **One fault:** `Sheet1!E13` =MIN(0.5*E12,B14/E10) divides preferred by market cap. Appendix B divides by price. Preferred is 0 here, so nothing changes.
- **Use:** 20 test vectors in group `K_downloads_creditgrades`. All 20 survival values and the DPS match.
